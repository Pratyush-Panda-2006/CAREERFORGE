      SYSTEMS MEMORY MANAGEMENT EASY • 5 PTS

      Two-Sum Memory Cache Lookup

      Problem Statement

      Given an array of allocated memory chunk sizes nums and a target buffer chunk target, return the indices of the two memory blocks such that they add up to exactly target.

      Example Test Case
      Input: nums = [2, 7, 11, 15], target = 9
      Output: [0, 1]
      Explanation: nums[0] + nums[1] == 2 + 7 == 9, so we return [0, 1].
      Constraints & Rules
      • Each input has exactly one valid solution.
      • You may not use the same element twice.
      • Target linear time complexity: O(n) using a Hash Map.

      Store each visited element in a Map (value => index). For each new element, check if target - current already exists in the map.
