Architectural Specifications & Mathematical Bounds

Kirsch-Mitzenmacher Double Hashing

Kirsch and Mitzenmacher (2006) proved that only two independent hash functions $h_1(x)$ and $h_2(x)$ are required to simulate $k$ hash functions with asymptotically identical false-positive bounds:

gi(x) = (h1(x) + i × h2(x)) mod m,   for i ∈ [0, k-1]

In our engine, $h_1$ is MurmurHash3 (32-bit x86) and $h_2$ is FNV-1a (32-bit) with odd-step bit conditioning (h2 | 1) >>> 0 to guarantee full coprime traversal of the address space.

Zero False-Negative Guarantee

A Bloom filter is a one-sided error probabilistic data structure:

  • Query Returns False (0): The item is guaranteed 100% to NOT be in the set. Zero false negatives.
  • Query Returns True (1): The item is either in the set, or a hash collision occurred (false positive).
  • FPR Upper Bound: $P(\text{FP}) \approx (1 - e^{-k n / m})^k$.
  • Optimal Hashes: $k = \frac{m}{n} \ln 2 \approx 0.693 \times \frac{m}{n}$.
