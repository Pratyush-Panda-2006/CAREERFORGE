About the binary format
LZW1 uses a 12-byte header: four magic bytes, the original UTF-8 byte count and the code count (32-bit big-endian). Codes are unsigned 16-bit big-endian. The byte dictionary starts at 256 entries and freezes at 65,536 entries. This standalone format is not ZIP. Invalid UTF-8 and malformed payloads are rejected; decoded output is capped at 256 KiB.
