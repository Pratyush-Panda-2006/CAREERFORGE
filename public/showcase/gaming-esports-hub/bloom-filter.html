    Kirsch-Mitzenmacher Double-Hashing Proof & Guarantees

    Standard Bloom Filters require k distinct hash functions, which can become computationally expensive. Kirsch & Mitzenmacher proved that two independent hash functions h1(x) (MurmurHash3 32-bit) and h2(x) (FNV-1a 32-bit) can simulate k independent hash functions without asymptotic loss in false positive probability using the recurrence relation:

    g_i(x) = (h1(x) + i × h2(x)) mod m,   for i ∈ {0, 1, ..., k - 1}

    Invariant Guarantee: If contains(x) returns false, x is provably absent (100% true negative recall). If contains(x) returns true, the match is either real or a false positive bounded by (1 - e-k·n/m)k.
