Loss range (₹)Scenarios

Each scenario draws a standard-normal shared shock, adds its scaled value to the base default probability, and clips the probability to 0–100%. Loans then default independently conditional on that probability. Each default loses principal minus the assumed recovery, rounded to one paisa per loan. Interest, fees, late payments, and additional borrower relationships are excluded. Clipping can change the average probability near the boundaries. A zero shock draws no shared adjustment.

Illustrative model. All inputs stay in memory. The same assumptions and seed reproduce the same scenarios; more scenarios reduce simulation noise, not model uncertainty.
