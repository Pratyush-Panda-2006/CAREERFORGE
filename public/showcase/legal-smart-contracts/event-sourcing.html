The boundary of this demonstration
Events and payloads are copied into private storage. Exposed events and states are defensive copies. Each event timestamp uses the local clock, advanced by one millisecond when needed to preserve strict order. Historical queries include every event at or before the selected timestamp.
Appending from a historical view still targets the current live state and retains every earlier event; there is no branch truncation or history edit. Playback projects one event every 500 ms and stops on pause, manual navigation, submission, reset or page exit. The ledger is limited to 500 events. Reset or reload clears it. This is in-memory application state, not durable storage, a cryptographic audit log or real on-chain contracts.
