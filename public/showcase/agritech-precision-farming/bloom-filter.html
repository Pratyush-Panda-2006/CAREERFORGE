What the estimate means

The model is (1 - exp(-k × n / m))k, with m = 256 bits, k = 4 and n = insertion attempts. It assumes independent, uniformly distributed hashes. Repeated insertions inflate n, so this is an approximation, not a guaranteed bound on the next query.

The engine uses deterministic non-cryptographic double hashing over UTF-8 bytes and never removes individual bits. Inserted strings remain possible members until reset. The separate demo insertion list identifies false positives for illustration; it is not part of the Bloom engine. This is not a security or authorization check.
