Read the measurements

FPS uses actual requestAnimationFrame callback intervals. Jitter is the mean absolute change between consecutive intervals. DOM/layout cost times 64 node updates and a forced geometry read; it is a rendering proxy, not direct GPU paint timing.

The workload index combines 60% frame rate (60 Hz reference), 20% jitter and 20% DOM/layout cost. It compares this workload in this browser, not overall hardware quality. Approximate Chromium JS heap readings are optional and excluded from the score; garbage collection may lower the reading.

Use the same browser, frame count and workload when comparing runs. Other tabs, power settings, display refresh rate and developer tools can affect results.
