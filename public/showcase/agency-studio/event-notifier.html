🎨 Agency Studio Reactive Toast Notification Queue

Prioritized client-side toast notification dispatcher with priority sorting, auto-dismissal timers, and Web Audio chimes.

Notification Engine Features

  • Priority Weight Capping: Danger (400) > Warning (300) > Success (200) > Info (100).
  • Intelligent Deduplication: Identical active alerts are merged without spamming user viewports.
  • Web Audio Dispatcher: Synthesizes dynamic sine-wave audio tones without external asset dependencies.
